# StackProof

**Prove what you built. Put your contribution on Bitcoin.**

StackProof is a full-stack Stacks dApp that lets builders submit contributions and record them as verifiable onchain proofs.

## What it does

1. Connect a Stacks wallet
2. Submit a contribution title, category, and proof URL
3. Confirm the transaction
4. Store the contribution onchain
5. Retrieve proofs from the Clarity contract

Each proof records:
- Contributor wallet address
- Contribution title
- Category
- Proof URL

## Live Demo

Production: https://bounty-taupe-chi.vercel.app

## Smart Contract

Network: **Stacks Testnet**

Contract name: `counter`

Functions:
- `submit-proof`
- `get-proof`
- `get-proof-count`

The contract stores proof data in a Clarity map and keeps a running proof count.

## Why StackProof?

Web3 builders create contributions across many platforms, but proving what they built can be fragmented.

StackProof explores a simple idea: make contributions easier to verify by putting a concise proof record onchain.

The goal is not to store the entire project onchain. Instead, StackProof stores the essential proof metadata while linking back to the original contribution.

## Scaffold Stacks Feedback

Scaffold Stacks provided a useful starting point for understanding how the frontend, wallet connection, generated contract hooks, and Clarity contract fit together.

The generated hooks made contract interaction easier once their structure was understood.

The main friction during development was discovering the exact generated hook names and argument structure. Clearer documentation or examples around generated hooks could make the onboarding experience easier for new builders.

Overall, Scaffold Stacks helped move the project from a contract idea to a deployed and working full-stack Stacks dApp.
